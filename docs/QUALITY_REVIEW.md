# v0.3 — ルールを減らす改善と検証

## 問題と変更
文字を読んでも理解しにくいという実プレイヤーの指摘を受け、文章の言い換えに加えてゲームの規則そのものを簡略化した。
予算・印章・判決書・倍率・階段の累積を削除。
覚える基本は「１枚選ぶ」「元気を残して８回」「高い点を取る」の３つ。
４種のカードを使い、影→鏡の連携と、星・休息の得失を残した。
端数・小数・得点式をなくし、実行前の点と元気をそのまま表示する。

## ５回のネイティブ自動プレイ
実Pyxelのupdate/drawと数字キー・決定入力を使用。手動プレイ／ブラウザプレイではない。
選択だけで実行されないこと、表示予測と実結果、結果からの同カード順再挑戦、説明画面・音・静止の切り替えを検証。

## バランスの機械的確認
100条件について、将来の全提示を知ったうえで選択を探索した。これは人間が出せる点の評価ではなく理論上限。
上限は55〜58点。探索で選ばれた最大点の経路100件のうち、星と休息は100件、影は69件に含まれた。
一律に休むだけ（28点）や目先の最大点を取るだけとは異なる選択が上限に必要。
ただし、これだけで面白さ・駆け引きの維持を証明はできない。実プレイヤーによる確認が必要。
詳細：`qa/simple-balance.json`。

### 改善の反復

1. 初見の意味：タイトルを「点を取ると、おばけの元気がへる」に変更。カードは元気を何個使う／回復するかを表示。影は所持0/1、鏡は通常3→8、消費と上限1を常時表示。実描画を見て確認。
2. 行動と結果：1秒で消えていた実行結果を、次のカードを選ぶまで保持。「影をためた／使った／1つのまま」を点数・元気の変化につなげた。おばけのそばにも影を描画。結果に案件番号、同じカード順の前回との差、影を使った鏡の回数を追加。数値・レイアウト・4秒後の保持を確認。
3. 起動体験：招待状のような枠・印・配色に統一。実行ファイルを非同期で読み込み、通信エラーと60秒の待ち時間超過を案内。OpenGLエラーでは再読み込みを主導線にせず、リンクのコピーと別ブラウザの案内を表示。クリップボードが使えない場合は選択可能なURLに退避。自己レビューでCSSがhidden属性を上書きする問題を発見し、修正。

### 検証

`node tools/check_boot.js` は生成HTMLの起動スクリプトで通信失敗・待ち時間超過・準備完了・OpenGL・コピーを検証。実際のWebGL初期化成功の証明ではない。
