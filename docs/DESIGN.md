# 冥界執行局 v0.1
架空の亡者への超常的な刑を、予算と生命力を管理して組み合わせる。
プレイヤーは執行官。刑の選択はタップ／マウス／数字キー。
480×270の横画面。日本語。8手番で終了、生命力0で早期終了。
8手番完遂時は最終判決を自動執行し40＋残存生命力÷2（切り捨て）点。
苦痛値はフィクションのゲーム内指標。現実の処刑手法は再現しない。

## 最小試作の合格条件
- タイトル→8手番または早期終了→結果→再挑戦が動く。
- 影→鏡、鐘→次の刑の組み合わせが得点に反映される。
- 各刑の選択前の予測得点と実際の加点が一致する。
- 予算不足でも記憶没収刑が提示され、進行不能にならない。
- 日本語文字がカードに収まる。
